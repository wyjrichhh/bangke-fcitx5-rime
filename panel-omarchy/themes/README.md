# Omarchy palette catalogue

Colour definitions from the local Omarchy repository (`themes/*/colors.toml` and optional `shell.toml`), distributed under the included MIT license. This catalogue contains 23 themes. Bangke resolves these through the same platform-theme reader as the current system theme; installed Omarchy themes and user themes override matching catalogue entries.

The `native` scheme follows the active theme. Named `omarchy_*` schemes remain fixed. Neither mode writes to other input methods’ shared Classic UI themes.
